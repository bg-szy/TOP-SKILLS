## 📌 为什么选择 TOP-SKILLS？

Claude Code 的自定义指令（`SKILL.md` 文件）能最大化 Claude 的能力——代码审查、重构、测试生成、架构设计等。**TOP-SKILLS** 帮你把这些技能一网打尽：

| 优势 | 说明 |
|------|------|
| **🌐 统一入口** | 从 13 个精选仓库收集 3,900+ 个技能，不用到处找 |
| **🔄 每日同步** | 每天自动更新，永远最新 |
| **✅ 质量保障** | 自动安全检测、去重、格式验证 |
| **🔍 智能搜索** | 网页看板支持搜索、筛选、排序、图表、趋势 |
| **💰 零成本** | GitHub Pages 纯静态站点，无需服务器 |

## 🚀 快速开始

```bash
# 1. 在线浏览
打开 https://bg-szy.github.io/TOP-SKILLS/

# 2. 直接使用技能
claude -p "请参考 https://github.com/bg-szy/TOP-SKILLS/blob/master/skills/marketplace/skill-name/SKILL.md 审查代码"

# 3. 克隆到本地浏览
git clone https://github.com/bg-szy/TOP-SKILLS.git
cd TOP-SKILLS
python -m http.server 8080 -d site/
# 浏览器访问 http://localhost:8080

# 4. 使用本地技能文件
claude --skill ./skills/marketplace/skill-name/SKILL.md
```

## 🏗️ 架构

```
                    ┌──────────────────┐
                    │  GitHub 上游仓库  │
                    │ (13+ 个来源)      │
                    └────────┬─────────┘
                             │
                    ┌────────▼─────────┐
                    │  collect_skills   │  ← 每日自动收集
                    └────────┬─────────┘
                             │
                    ┌────────▼─────────┐
                    │  verify_skills    │  ← 安全与质量检查
                    └────────┬─────────┘
                             │
                    ┌────────▼─────────┐
                    │  generate_site    │  → site/data/skills.json
                    └────────┬─────────┘
                             │
                    ┌────────▼─────────┐
                    │  GitHub Actions   │  → gh-pages → 自动部署
                    └──────────────────┘
```
